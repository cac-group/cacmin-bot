## Chat command responses trim (slop text pass)

**Request.** Chat command responses carried mechanics/"how it works" prose that
duplicated the DM-only `/help` tree. Example: `/setratelimit` echoed the
rollover/emoji/count-reset rules after the confirmation.

required next-step command. Explanatory prose (how it works, rules, odds,
"the bot will…", bail help pointers) is dropped; that content already lives in
`src/commands/helpTree.ts` (DM-only via `/help`).

tail, `jail`/`customjail` success + usage, `/jails` footer, `/paybail` tail,
`/roll` and `/duel` no-arg rule blocks, `/giveaway` no-arg and `/treasury`
how-it-works, `payallfines` tail, deposit usage blocks, `/getsticker` tail,
`crawlidentities reset`, shared-account revoke tail, `adjustbalance` no-arg
help, treasury external-deposit tail.

**Second pass.** Swept the handlers/services that emit user-facing text and
trimmed remaining no-value confirmations: `addidentityblock` "matching users
will be jailed…" and the deposit confirmation "funds are now available". Kept
short usage/syntax, required next-step commands, error causes, and enforcement
notices (they carry material value). `/bailhelp`, `/regexhelp`, `/spamreacthelp`,
`/identityblockhelp`, `/rollodds`, `/ratelimits` and the DM-only `/help` tree are
deliberate documentation and were left intact.
