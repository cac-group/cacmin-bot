# 2026-10-31 — Juno migrated to gRPC

**Scope.** Removed the last REST and Tendermint-RPC paths. JUNO now uses the
same shared `CosmosGrpcService` as CAC, with Polkachu Juno gRPC
(`juno-grpc.polkachu.com:12690`, plaintext) as the single endpoint.

**What moved.**
- `src/services/cosmosGrpcService.ts` is the generic per-chain client
  (balance, `GetTx`, `GetTxsEvent`, `GetLatestBlock`, `SIGN_MODE_DIRECT`
  signing, `BroadcastTx`).
- `JunoGrpcService` and `OsmosisGrpcService` are thin per-chain instances.
- JUNO deposits, startup monitoring, treasury balances, bail payment
  verification, rate-limit payment verification, and withdrawals all use
  `JunoGrpcService`.
- `@cosmjs/stargate` and the old `cosmosRestService` / `junoRpcUrl` /
  `junoApiUrl` paths were removed. Configuration now exposes `JUNO_GRPC_URL`,
  `JUNO_CHAIN_ID`, and `JUNO_CONFIRM_TIMEOUT_MS`.
- The Osmosis wallet uses the same mnemonic/key as JUNO with the `osmo` prefix;
  the separate `OSMOSIS_USER_FUNDS_ADDRESS` override was removed.
- Deposit watermarks are seeded to the chain tip on a fresh deployment for
  both chains, and both use the same oldest-first, height-bounded scan.

**Verification.** `bun run build`, `bun run lint`, `bun run test` (266 passing),
and `bun run test:coverage` green. Live Polkachu Juno gRPC checks covered
`GetLatestBlock`, `Balance`, and `GetTxsEvent`; Osmosis checks remain green.
No deployment performed.
