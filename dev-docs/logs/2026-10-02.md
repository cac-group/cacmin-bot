## 2026-10-02 — Centralize tunable constants into `src/config.ts`

**Problem.** Dozens of operational values (scheduler intervals, detection
thresholds, game economics, fee settings, session timings, branding strings)
were module-level literals scattered across `src/`. Operators had to edit and
rebuild to change them, and some values were duplicated. Three config
inconsistencies were also live.

**Changes.**

- `config.ts` gained groups: `intervals`, `reactionSpam`, `gambling`, `duel`,
  `defaultJailBailAmount`, `chain`, `price`, `timing`, `limits`, `indexer*`,
  `identityCrawl*`, `botIdentity`. New env overrides documented in
  `.env.example`.
- `bot.ts` scheduler intervals now read `config.intervals.*`.
- `reactionSpam.ts` reads `config.reactionSpam.*`; bio patterns and jail
  messages moved into config as content constants.
- Game economics: `gambling.ts` (`MIN_BET`/`MAX_BET`/`WIN_MULTIPLIER`),
  `duelService.ts` (`DUEL_TIMEOUT_SECONDS`/`MIN_WAGER`/`MAX_WAGER`), and
  `jailService.ts` (`DEFAULT_JAIL_BAIL_AMOUNT`) now source values from config
  while keeping their exported names for importers.
- Withdrawal gas price/limit moved to `config.chain`; the network fee is now
  derived from the configured gas price instead of a hardcoded `0.075`.
- Price service cache/id/rolling-window/retention/URL moved to `config.price`.
- Session/dedupe/cache timings (`menuSession`, `autoDelete`, `callbacks`,
  `identityBlocks`, `spamReacts`) moved to `config.timing`.
- Regex limits and random-delete defaults moved to `config.limits`.
- Indexer tuning and identity-crawl throttle/retries moved to config.
- Support username (`banbabybot`) and sticker pack name/file id moved to
  `config.botIdentity`; no more hardcoded `t.me/banbabybot` or `CACGifs`.
- Removed redundant Juno URL fallbacks in `junoService`, `ledgerService`,
  `unifiedWalletService`, `rpcTransactionVerification`; `junoApiUrl` is now a
  required config field.
- Deduplicated `VIOLATION_SELECT` (exported from `violationService.ts`, imported
  by `commands/payment.ts`).

**Inconsistencies fixed.**

- `config.restrictionDurations` deleted (declared, populated, never read).
- `BOT_USERNAME` removed from `.env.example` (documented as required, never
  read).
- `.env.example` no longer lists `BOT_TREASURY_ADDRESS` as removed; it is live
  and now documented as optional.

**Tests.** Updated `config` mocks in `identityCrawl`, `chatIndexer`,
`unifiedWalletService`, `duelService`, and `wallet` tests to include the fields
their modules read at import time. Suite: 192 passing; `tsc` build and Biome
clean. `bun run validate` still exits 1 for the pre-existing missing fine
configuration (unrelated).

**Follow-up.** `config.ts` is now ~570 lines. If it grows further, split into a
`src/config/` directory by group; not warranted yet.
